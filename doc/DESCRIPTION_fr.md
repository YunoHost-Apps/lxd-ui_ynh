LXD UI est l'interface web officielle de LXD : créer et gérer les instances, les
images, les réseaux, le stockage et les profils, avec une console sur les
conteneurs et machines virtuelles. C'est LXD qui la sert, l'app `lxd` doit donc
être installée au préalable.

**Quiconque est autorisé ici contrôle entièrement LXD**, quel que soit son compte
YunoHost : NGINX s'authentifie avec un certificat qui a tous les droits.
